# Kalpana Bannad — Portfolio

A responsive static portfolio with light/dark mode, project links, writing, achievements and certificate gallery.

## Run locally
Open `index.html` directly, or in VS Code install **Live Server** and choose **Open with Live Server**.

## Deploy
This is a static site, so the entire folder can be deployed to GitHub Pages, Netlify, Render Static Site, or Vercel.

## Edit
- Main content: `index.html`
- Design: `styles.css`
- Theme/menu/animations: `script.js`
- Images and resume: `assets/`
